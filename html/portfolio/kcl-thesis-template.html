KCL PhD Thesis Template

Year 2026
Role Creator · Maintainer
Format LaTeX · PDF · BibTeX
Code Open in Overleaf

A clear, modular LaTeX template for King's College London PhD theses. It separates front matter, chapters, appendices, package configuration and bibliographies so a long-form research document remains easy to navigate and maintain.

The template includes an example compiled thesis, dedicated bibliographies for references and personal publications, and a structure tested with Overleaf, TeXShop and command-line LaTeX workflows. It is available as an open GitHub repository and as a ready-to-copy Overleaf template.
